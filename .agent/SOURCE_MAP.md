## Public Duck Source

- `Sources/Duck/Migration.swift`: final accepted public `Migration: Sendable` protocol with exact name-only durable identity, default Swift type-name implementation, declarative `up`/`down` `MigrationPlan`s, plus internal immutable `RegisteredMigration` name snapshot and registry validation. Names are captured exactly once when a `Migrator` is created; blank and duplicate names fail before database work.
- `Sources/Duck/MigrationPlan.swift`: final accepted declarative migration authoring layer. `MigrationPlan` is intentionally non-Sendable and ordered; `Run` is the imperative `DuckTransaction` escape hatch; `MigrationBuilder` accepts only SQLable, `Run`, nested `MigrationPlan`, and a non-empty ordered block.
- `Sources/Duck/Migrator.swift`: immutable public migration runner created through `DatabaseIdentifier.migrator(_:)`; public migrators retain only the lightweight identifier and resolve the canonical runtime lazily at operation time. Exact operations are `migrate()`, `revert()`, `revert(last:)`, `revert(to:)`, and `revertAll()`, all returning the resulting current `UInt` batch. A migrate pending set uses one atomic transaction; revert is newest-batch-first and factual-id-desc within each batch with missing-source preflight and down-before-delete semantics.
- `Sources/Duck/MigrationError.swift`: final accepted compact public migration semantic error domain for registry, coordinator, durable-history integrity/numeric boundaries, missing revert source, and invalid revert target; transaction/body/native errors remain in their existing domains.
- `Sources/Duck/MigrationRunCoordinator.swift`: process-local actor coordinator over logical named-memory/file canonical-path identities. Equivalent public identifiers converge on one canonical runtime and overlapping migration runs map to `concurrentRun`; unrelated identifiers remain independent. The weak file-owner conflict seam remains internal regression protection for exact-runtime tests.
- `Sources/Duck/MigrationHistory.swift`: final accepted `__swiftduckdb.migrations` owner for exact `id / name / batch / applied_at` schema bootstrap/validation, id-ascending load, dense retained-batch integrity, name-based caller-ordered pending selection, checked UInt/BIGINT conversion, `MAX(retained id)+1` allocation/preflight, exact TIMESTAMPTZ `applied_at`, and exact-id insert/delete helpers.
- `Sources/Duck/Database+Migrations.swift`: public nonthrowing `DatabaseIdentifier.migrator(_:)` factory plus an internal exact-runtime regression seam; application code does not retain a live Database owner.

- `Sources/Duck/DatabaseIdentifier.swift`: public lightweight `Hashable & Sendable` logical identity for file-backed, named-memory, and unique-memory databases; owns no native handle or mutable runtime state. A private process-lifetime actor registry lazily resolves equivalent identifiers to one canonical live runtime. Public conveniences open a Connection, run a scoped Connection/transaction, or create an explicit bounded pool.
- `Sources/Duck/Database.swift`: internal actor-free `Sendable` live runtime owner for one `NativeDatabase`, one canonical `DatabaseIdentifier`, and one Observation coordinator; consumer code cannot construct or retain this type through normal import.
- `Sources/Duck/Database+Observation.swift`: public synchronous `DatabaseIdentifier.observe(_:)` factory plus internal exact-runtime regression seams; equivalent identifiers share canonical-runtime invalidation while external process/file mutation remains out of contract.
- `Sources/Duck/QueryObservation.swift`: public reusable latest-state `AsyncSequence<QueryResult>` whose public source is a lightweight identifier resolved lazily per iterator to the canonical runtime; each iterator owns an independent private refresh Connection, bounded result delivery, equal-result suppression, cancellation-local termination, and READ ONLY refresh routing.
