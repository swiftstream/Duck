## Package / Public Surface

- `Package.swift`: SwiftPM manifest for the Duck library product, public Duck target, SQL dependency from 3.1.0, and both Swift Testing targets. It uses Swift tools 6.3, iOS 15+, macOS 12+, and Swift language mode 6. For DuckDB v2.0.0 it selects a precompiled `Cduckdb` XCFramework binary target on macOS and the generated C++17 `Cduckdb` source target on non-macOS platforms.
- `Package.resolved`: intentionally ignored local SwiftPM resolution evidence, not committed source-of-truth; current accepted SQL3 resolution maps SQL `3.1.0` to revision `b0c81191c3494d91b84b5382092e99c64d5c4647`.
- `.swift-version`: tracked exact Swift `6.3.3` toolchain pin.
- `README.md`: public query, reusable-Statement, managed + flat explicitly finalized Transaction, latest-state `QueryObservation`, ordinary and Transaction Appender including fixed selected columns, exact temporal/Foundation.Date/Interval values, exact Foundation.Decimal/DECIMAL, and flat Codable / Model Layer documentation. Observation examples preserve same-identifier canonical-runtime/native-READ-ONLY/latest-state boundaries; executable query examples use SQL, and ordinary String execution/manual `$1` placeholder APIs are not taught.

## Current canonical pooling and Observation

Use `Database.swift`, `Database+Runtime.swift`, `CanonicalPoolController.swift`, `ConnectionPool.swift`, `ConnectionPoolLease.swift`, and the lease authority/lifetime files below for ownership and configuration. Native retirement ordering is in `Connection+Runtime.swift` and `Native/NativeConnection.swift`; see `NativeConnectionRetirementTests.swift` for real C-boundary lifecycle regression evidence. Reactive refresh and publication use `QueryObservation.swift`, `ObservationCoordinator.swift`, and ordinary/transaction/Appender execution paths. `ObservationDeterministicStressTests.swift` covers bounded demand and committed-state convergence. Load the matching source-owned skill when working on consumer code. Project Memory owns accepted implementation facts; Task Archive owns milestone history.

## Public Duck Source

- `Sources/Duck/Migration.swift`: final accepted public `Migration: Sendable` protocol with exact name-only durable identity, default Swift type-name implementation, declarative `up`/`down` `MigrationPlan`s, plus internal immutable `RegisteredMigration` name snapshot and registry validation. Names are captured exactly once when a `Migrator` is created; blank and duplicate names fail before database work.
- `Sources/Duck/MigrationPlan.swift`: final accepted declarative migration authoring layer. `MigrationPlan` is intentionally non-Sendable and ordered; `Run` is the imperative `DuckTransaction` escape hatch; `MigrationBuilder` accepts only SQLable, `Run`, nested `MigrationPlan`, and a non-empty ordered block.
- `Sources/Duck/Migrator.swift`: immutable public migration runner created through `Database.migrator(_:)`; public migrators retain only the lightweight identifier and resolve the canonical runtime lazily at operation time. Exact operations are `migrate()`, `revert()`, `revert(last:)`, `revert(to:)`, and `revertAll()`, all returning the resulting current `UInt` batch. A migrate pending set uses one atomic transaction; revert is newest-batch-first and factual-id-desc within each batch with missing-source preflight and down-before-delete semantics.
- `Sources/Duck/MigrationError.swift`: final accepted compact public migration semantic error domain for registry, coordinator, durable-history integrity/numeric boundaries, missing revert source, and invalid revert target; transaction/body/native errors remain in their existing domains.
- `Sources/Duck/MigrationRunCoordinator.swift`: process-local actor coordinator over logical named-memory/file canonical-path identities. Equivalent public identifiers converge on one canonical runtime and overlapping migration runs map to `concurrentRun`; unrelated identifiers remain independent. The weak file-owner conflict seam remains internal regression protection for exact-runtime tests.
- `Sources/Duck/MigrationHistory.swift`: final accepted `__swiftduckdb.migrations` owner for exact `id / name / batch / applied_at` schema bootstrap/validation, id-ascending load, dense retained-batch integrity, name-based caller-ordered pending selection, checked UInt/BIGINT conversion, `MAX(retained id)+1` allocation/preflight, exact TIMESTAMPTZ `applied_at`, and exact-id insert/delete helpers.
- `Sources/Duck/Database+Migrations.swift`: public nonthrowing `Database.migrator(_:)` factory plus an internal exact-runtime regression seam; application code does not retain a live Database owner.

- `Sources/Duck/DatabaseIdentifier.swift`: deprecated source-compatible typealias to `Database`; no separate runtime or resource ownership.
- `Sources/Duck/Database.swift`: public lightweight `Hashable & Sendable` file/named-memory/unique-memory identity; private process-lifetime actor registry; canonical configuration, pool access, scoped/manual lease and managed transaction entrypoints.
- `Sources/Duck/Database+Runtime.swift`: internal `Database.Runtime` owns native database, canonical pool controller, and Observation coordinator; native connection construction is internal, not a public capacity bypass.
- `Sources/Duck/CanonicalPoolController.swift` / `ConnectionPool.swift` / `ConnectionPoolLease.swift`: canonical initialization/configuration, bounded reusable resource ownership, checkout/return, cancellation, retirement, physical disconnect before capacity release, terminal failure fencing and shutdown.
- `Sources/Duck/ManualConnectionLifetime.swift` / `ConnectionAuthority.swift`: exact manual/scoped lease lifetime and authority; stale handles cannot revive on core reuse.
- `Sources/Duck/Database+Observation.swift`: public synchronous `Database.observe(_:)` factory plus internal exact-runtime regression seams; equivalent identifiers share canonical-runtime invalidation while external process/file mutation remains out of contract.
- `Sources/Duck/QueryObservation.swift`: public reusable latest-state `AsyncSequence<QueryResult>` whose public source is a lightweight identifier resolved lazily per iterator to the canonical runtime; each iterator owns a registration, refresh worker, and bounded result delivery, while each READ ONLY refresh borrows a scoped canonical-Pool Connection lease and holds no Connection while idle; equal-result suppression and cancellation-local termination remain unchanged.
- `Sources/Duck/ObservationCoordinator.swift`: canonical-runtime-local subscription/invalidation coordinator, bounded latest invalidation delivery, table/database dependency matching, qualification closure, and ASCII-case canonical identity.
- `Sources/Duck/Connection.swift`: public thin lease-bound actor handle and public forwarding entrypoints, including explicit manual `release()`.
- `Sources/Duck/Connection+Runtime.swift`: internal reusable native core, admission, ordinary/transaction/Statement/Appender execution, pending execution, cancellation, native failure and cleanup, Observation refresh and publication. Appender impact is conservatively Database-wide, not target-only.
- `Sources/Duck/ResultRow.swift`: Swift-owned materialized row facade and exact named/positional typed extraction.
- `Sources/Duck/ResultRow+Decodable.swift`: Codable decoder over `Value`-backed result rows, including native scalar interception, one-dimensional LIST unkeyed decoding, one-level keyed STRUCT decoding, exact missing/NULL/type-mismatch semantics, raw-value enum fallback, duplicate STRUCT-member rejection, and recursive-composite rejection beyond the closed LIST/STRUCT P0 boundaries.
- `Sources/Duck/ModelEncoder.swift`: accepted `ModelEncoder`/`EncodedModel` plus shared `ModelScalarEncoder` authority used by model encoding and Table persistence extraction; preserves root omission versus explicit NULL, captures Array properties as native one-dimensional `Value.list`, captures exactly one nested keyed Codable level as `Value.structure`, gives STRUCT-specific `encodeIfPresent` explicit-NULL semantics while preserving root Optional omission, and rejects deeper keyed/unkeyed recursive composites without reflection/stringification fallback.
- `Sources/Duck/Table+Persistence.swift`: persistence field extraction, `PreparedModelValue`/`BoundModelValue` prepared-binding carriers, schema-qualified SQL INSERT/UPDATE builders, public Database-backed insert/update/delete/UPSERT conveniences through canonical pooled leases, matching explicit Connection and DuckTransaction overloads, and typed `Collection where Element: Table` `batchInsert(on:)` for all three targets. Batch insertion reuses the same persistence-field extraction, fully preflights rows, preserves DEFAULT versus explicit NULL semantics and input order across contiguous column-signature runs, and executes through selected-column Transaction Appenders; identifier and Connection overloads supply the managed atomic transaction through the existing Connection engine.
- `Sources/Duck/Statement.swift`: public reusable prepared-statement capability, private dynamic Parameter markers/layout validation, originating-Connection ownership, ordinary and explicit-DuckTransaction query/execute APIs, operation-lifetime retention, Appender-body same-Connection guard routing, and actor-routed registry cleanup.

## Internal Native Adapter

- `Sources/Duck/Native/NativeDatabase.swift`: internal DuckDB database owner and native connection factory; narrow reviewed `@unchecked Sendable` owner plus opt-in synchronized native lifecycle witness.
- `Sources/Duck/Native/NativeConnection.swift`: non-Sendable native connection owner, prepare/interrupt/raw-handle scoped access.
- `Sources/Duck/Native/NativeDuckDBError.swift`: internal operation-tagged native error transport.

- `Sources/Duck/Native/NativeAppender.swift`: Appender RAII owner with strong NativeConnection lifetime, fixed selected-column setup and active descriptor copying before rows, whole-row scalar/LIST/STRUCT typed-value preflight before native mutation, exact same-sign integer and temporal/Interval/Decimal/UUID handling, native LIST/STRUCT parent-value ownership through `ownedValues`, complete-row/end-row mutation, explicit close/destroy, discard via clear+destroy, copied diagnostics, and ambiguous-buffered-data cleanup signaling.
- `Sources/Duck/Native/NativeLogicalTypeCopier.swift`: shared deep-copy adapter for caller-owned DuckDB logical-type handles, recursive child handles, aliases/member names/ENUM strings, and deterministic destruction/free ownership.
- `Sources/Duck/Native/NativeScalarCodec.swift`: availability-free HUGEINT/UHUGEINT word and UUID canonical/physical transforms plus availability-gated Swift Int128/UInt128 bridges.
- `Sources/Duck/Native/NativePendingResult.swift`: pending-result RAII owner and pending task/final execution bridge.
- `Sources/Duck/Native/NativeResult.swift`: result RAII owner, one-time result-column logical metadata deep-copy/destruction, chunk/vector materialization, NULL handling, Swift-owned scalar materialization, validity-first exact temporal/Interval/Decimal reconstruction, native LIST vector materialization with offsets/child validity/ENUM widths, and native STRUCT materialization before generic flat-vector access using descriptor names, same-row child vectors, explicit child logical-type ownership, and recursive-composite rejection.
- `Sources/Duck/Native/NativeListValueCodec.swift`: native one-dimensional LIST construction plus shared target-aware scalar-value factory. LIST owns parent validation, child-target derivation, empty-list non-null pointer behavior, child/value lifetimes, exact ENUM mapping, and `duckdb_create_list_value`; the scalar factory is reused by STRUCT and never constructs recursive composites.
- `Sources/Duck/Native/NativeStructValueCodec.swift`: native immediate-keyed STRUCT construction with borrowed parent target, exact case-sensitive source/target name-set validation, source-to-target reordering, owned child logical types and temporary values, explicit native NULL members, shared scalar conversion, nested-composite rejection, and `duckdb_create_struct_value` parent-type construction.
- `Sources/Duck/Native/NativeTemporalCodec.swift`: dedicated exact PureDate/PureTime/DateTime civil and timestamp codec with finite DATE guarding, exact 24:00/TIME_NS handling, target-precision validation, floor-consistent negative decomposition, and checked overflow/range behavior.
- `Sources/Duck/Native/NativeFoundationDateCodec.swift`: dedicated exact Foundation.Date/TIMESTAMPTZ codec using signed Int64 microseconds since the Unix epoch, with per-value equality, infinity/non-finite rejection, and checked overflow handling.
- `Sources/Duck/Native/NativeIntervalCodec.swift`: dedicated exact shared `Interval` ↔ `duckdb_interval` codec; finite months/days use exact Int32 narrowing, microseconds remain Int64, mixed-sign/non-normalized values are preserved, and semantic infinity/out-of-range values are rejected only at native Prepared/Appender boundaries.
- `Sources/Duck/Native/DecimalExactCodec.swift`: byte-identical accepted DCT128-v1 exact Foundation.Decimal coefficient/scale codec using bounded availability-free signed-word transport, no Double/raw-layout/stdlib-Int128 dependency, exact W1...W38 fit, and exact reverse reconstruction/revalidation.
- `Sources/Duck/Native/NativeDecimalAdapter.swift`: production adapter for explicit resolved DECIMAL(W,S) authority, targetless canonical natural W/S including zero `1/0`, nonfinite/rounding/width rejection, direct native decimal conversion, and exact result reconstruction validation through `DecimalExactCodec`.
